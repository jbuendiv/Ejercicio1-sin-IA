# Ejercicio1-sin-IA
Ejercicio pokedex hecho con react y sin IA

Uso de la PokeAPI.
Funcionalidades principales (buscador, lista, tipos)

# Tecnologías Utilizadas
React.js
CSS Modules
Fetch para la petición

# Requisitos Previos
npm (versión recomendada 11.11.0)

**cd pokedex**

**npm install**

**npm start**

**http://localhost:3000**
